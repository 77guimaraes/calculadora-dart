# Calculadora em Dart 🎯

Exercício simples de lógica e fundamentos de **Dart**, feito durante os estudos de **Flutter** na Alura e para manter a prática ativa no GitHub.

## 📌 Sobre o projeto

Calculadora de terminal (`dart:io`) que recebe dois valores (`double`) e realiza `+`, `-`, `*` ou `/`, validando a operação escolhida (`getOperacao()`) e executando o cálculo (`calcular()`).

## 📂 Onde encontrar no repositório

O código fica em **`bin/calculadora.dart`** (abra a aba [Code](https://github.com/77guimaraes/calculadora-dart) > pasta `bin` > `calculadora.dart`).

## ▶️ Como executar

Com o **Dart SDK** instalado, rode na raiz do projeto:

```bash
dart run bin/calculadora.dart
